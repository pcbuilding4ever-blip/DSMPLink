# DSMPLink — Minecraft ↔ Discord linking

Paper 1.21.11 plugin for DSMP PvP.

The plugin automatically opens a native Minecraft Dialog when a player joins. The player enters the six-digit code generated by the Discord bot, and the plugin sends the code plus Minecraft identity data to the verification API.

Configure `plugins/DSMPLink/config.yml` after the first build/install:

```yaml
api-url: "https://YOUR-BOT-API/verify"
api-secret: "A-LONG-RANDOM-SECRET"
reopen-delay-seconds: 2
require-link-on-join: true
```

The Discord API should accept JSON with `code`, `minecraftUuid`, and `minecraftName`, authenticated by the `X-DSMP-Link-Secret` header.
